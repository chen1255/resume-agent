# 岗位 JD：高级前端工程师

## 岗位职责
- 负责公司核心 SaaS 产品的 Web 前端架构设计与开发，保障复杂业务下的性能与可维护性；
- 主导前端工程化体系建设（构建、CI/CD、组件库、监控）；
- 指导初中级工程师，承担技术方案评审与 Code Review。

## 任职要求
- 本科及以上学历，计算机相关专业优先；
- 5 年以上前端开发经验，精通 JavaScript / TypeScript；
- 精通 React 生态（Hooks、状态管理、SSR），有大型中后台或数据密集型应用经验；
- 熟悉前端性能优化，能独立定位并解决首屏、渲染、内存类问题；
- 有组件库 / 设计系统落地经验者优先；
- 良好的沟通与跨团队协作能力。

## 加分项
- 有微前端、Monorepo 实战经验；
- 有前端监控 / 稳定性体系建设经验；
- 开源贡献或技术博客。
